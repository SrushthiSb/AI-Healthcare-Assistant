# CareFlow AI — Healthcare Education Assistant

CareFlow AI is an AI-powered web application that explains
general health concepts in simple, accessible language.

## Features
- AI-generated educational responses
- Simple, interactive web interface
- Example questions
- Input validation and basic error handling
- Health education disclaimer and safety-oriented instructions

## Technologies
- Python
- Streamlit
- Google Gen AI SDK
- Generative AI prompt engineering

## Run Locally

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Create a `.env` file containing:

   GEMINI_API_KEY=your_api_key
   GEMINI_MODEL=your_supported_model_name

5. Start the application:

   streamlit run app.py

## Limitations
This project is an educational prototype. AI-generated
information may be inaccurate or incomplete. It does not
provide medical diagnoses or personalized treatment.

## Responsible AI
Do not enter personal or identifiable medical information.
Verify important health information with qualified professionals.
